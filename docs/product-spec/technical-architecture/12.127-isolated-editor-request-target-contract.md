Perluas hanya fixture12.122–12.126 dengan native HTTPS loopback gateway command-only.

request upstream atau membaca/meneruskan body. Semua target lain403 status-only
unavailable/private-no-store/Expires0/Pragma/no-referrer/nosniff, Connection close;
tidak normalize/decode/redirect/fallback atau derive trusted target dari header.
