# 12.19 — Published snapshot read foundation — LOCKED

This bounded database contract follows P01 `/{handle}`, P02 `/{handle}/spill`,
P04 Resource detail, OD-NAV-005 and the publication snapshots in 12.18. It does
not enable public routes, anonymous RPC access, click transport or first Publish.

Public Identity lookup uses a normalized ASCII Handle or protected historical
alias. Resolve the same stable Owner, current canonical Handle, active account,
completed onboarding and Published Identity lifecycle. Invalid/unknown Handle,
unpublished/inactive Owner and hidden/archived Identity all return the same
`unavailable` payload. Never expose private state/reason, Owner UUID, Working
revision, receipt, selected private media key or unselected Draft content.

The DTO contains only published display name, bio, starter and permitted
Connection context. Connection URL is returned only when the exact URL/hash has
a fresh safe verdict at one wall-clock validation time. Otherwise preserve the
published block's context with `available=false` and no destination URL. Spill
availability derives only from Published Resource snapshots with currently safe
sources, never reservations or private Drafts. Resource detail requires that
same public Owner/Identity gate, current Owner-scoped positive reference and a
Published Resource snapshot with fresh exact-source safety. Unknown, unsafe,
hidden/archived or mismatched-owner references are uniformly unavailable.

Readers use explicit visibility predicates in a narrowly scoped definer function
because private core tables remain inaccessible. They accept public locators
only and never use caller authentication to expose more data; future anonymous
and signed-in viewers receive the same published DTO. All Data API execution
grants remain withheld at this checkpoint. Tests grant execution inside their
rolled-back fixture transaction to verify the anonymous visibility boundary.
Future enabling requires route/parser, public safety-click transport, caching,
private media transport and workspace/UI handoff verification.

Product reads remain unavailable until mandatory primary-image/marketplace
preparation and its public renderer are implemented. Selected private Profile
Media is not silently dropped or exposed by this foundation; such a snapshot
is unavailable until the public media contract exists.
