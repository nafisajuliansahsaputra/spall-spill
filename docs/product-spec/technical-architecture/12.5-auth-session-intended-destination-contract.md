---

## 1. Current authentication authority

The production authentication provider is **Supabase Auth**.

MVP Owner authentication methods are:

- Email + Password;
- Google OAuth.

Historical Firebase authentication decisions are superseded where they conflict with the current Stage 12 technology authority.

Authentication remains separate from the stable Spall Spill Owner identity and from authorization.

---

## 2. Next.js SSR session model

The web application uses:

- `@supabase/supabase-js`;
- `@supabase/ssr`;
- cookie-based Supabase SSR sessions;
- PKCE-compatible authentication flows;
- request-scoped Supabase server clients;
- Next.js Proxy for normal auth-token refresh.

A Supabase server client must not be stored in module-global mutable state or reused across unrelated requests.

---
