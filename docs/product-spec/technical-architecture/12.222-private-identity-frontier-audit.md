### Pemilihan gap dan langkah aman berikutnya

Pilih **fondasi private Media/Image Working input** sebagai dependency leaf
berikutnya. Media belum memiliki typed workspace input/payload/read/mutation;
Text dan Contact sudah memiliki primitive independen. Spill CTA juga belum ada,
tetapi valid active-public CTA bergantung public Spill/publication eligibility;
Media input murni bisa diaudit/dibangun tanpa memilih tujuan eksternal, mengakses
R2/live provider atau mengaktifkan publikasi. Ini urutan implementasi teknis,
bukan menghapus/deprioritaskan kewajiban Spill CTA/full D02.

Sebelum coding, JIT berikutnya harus mengunci **hanya input/diagnostic lokal**:
exact shape/nullable intermediate representation, platform asset-reference shape,
raw recoverable alt/accessibility text dan engineering envelopes. Bedakan syntax
selector dari same-Owner canonical-asset authority. Pinned spec tidak menetapkan
field names/limit/asset-binding tersebut; jangan mengaku itu semantics historis
atau menganggap alt UX/decorative policy/optional destination sudah diputuskan.

Kontrak input tidak boleh melakukan upload/fetch/attachment, menerima arbitrary
URL/object key/presigned credential sebagai canonical asset authority, mengklaim
Saved/Live/owned/sanitized, menambah Media ke general ready decoder, atau memilih
format/size/transformation/storage/public destination diam-diam. Source input
Text/Contact bisa menjadi pola strict/null/recovery/no-I/O, bukan DTO yang disalin
tanpa audit. Database binding/kind/Owner/asset lifecycle/CAS/GC dan sanitized safe
delivery memerlukan kontrak serta evidence tersendiri sebelum persistence/mounting.

Tidak ada Owner action yang diperlukan untuk pure input/JIT audit ini. Jika fase
upload/deployment kelak nyata membutuhkan credential/provider config/paid tier/
irreversible choice, blok hanya path itu sesuai Protocol; jangan menyimpulkannya
dari ketiadaan deployed provenance. Gate137 tetap terbuka dan tidak diaudit ulang
sebagai alasan memperbanyak fixture atau mengubah hosting.
