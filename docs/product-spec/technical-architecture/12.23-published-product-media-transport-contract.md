## Transport and revocation

`GET /media/product/{handle}/{reference}` is technical media transport, not a new
journey screen. It needs no viewer account/session refresh. Only the server
resolver selects storage; route query parameters cannot select assets/URLs.
Share 12.21 bounded canonical download and fixed no-store/nosniff/same-origin/CSP
response behavior. Verify strict descriptor/reference binding, deadline, MIME,
declared/actual bytes and RIFF/WebP framing. After download re-resolve and compare
the entire descriptor; visibility, reference or publication replacement denies
delivery. All invalid/unavailable/provider/credential failures return uniform 404
without private keys, signed redirects, provider errors or conditional/range
cache authorization shortcuts. Already delivered bytes cannot be revoked.
