Stage a server-only unmounted identity resolver. Require an injected runtime
metadata reader, explicit bounded namespace and 32–64 byte server HMAC key.
No environment/credential reads, provider calls, request-header parsing, account
requirement, public route/grant, publication or production configuration.

The reader returns exactly `{ address: string }` from a trusted runtime source.
This dependency is an attestation boundary, not proof the deployed source is safe.
Do not supply arbitrary Forwarded/X-Forwarded-For headers, request body, cookies or
client-chosen IDs as that source. Actual upstream proxy stripping/provenance must
be evidenced separately before enabling. Origin/HMAC is not authentication or
authorization and must never replace Published-context or ownership checks.

Accept only one bounded bare IP literal, without whitespace, brackets, zone IDs,
ports, lists, hostname, shorthand/hex/octal IPv4 or leading-zero octets. Validate
with Node isIP; normalize IPv4 decimal and IPv6 to the full 16-byte hex address.
Collapse IPv4-mapped IPv6 to the same IPv4 subject; other IPv6 addresses retain
all 128 bits. No subnet aggregation or public/private-address filter: trusted
runtime determines the client, this is not an outbound SSRF target validator.
HMAC-SHA256 the domain/version, namespace and normalized address, separated by
NUL; return only base64url digest. Snapshot namespace/key at construction and
copy key bytes. Never return/log/store raw addresses or keys. Keyed pseudonymization
does not establish anonymity; rotation/namespace changes reset budget partitions.

Fail closed to null on invalid configuration/metadata, reader errors, abortion,
nonfinite/backward monotonic clock or a reader taking 500 ms. One fresh read per
request, no caching/retry/fallback. Late completion must not derive a subject.
The outer 12.40 two-second identity/EVAL deadline remains mandatory.
