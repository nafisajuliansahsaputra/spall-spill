# 12.15 — S6 private preview foundation

LOCKED bounded first S6 checkpoint. Authority: full pinned O01-S6, J1–J4,
12.9–12.14 and Working-versus-Published isolation. Preview is mandatory before
first publication; reaching it is not onboarding completion or activation.

An authenticated current-Owner resolver returns one coherent read snapshot of
current Handle, progress revision, Identity/Starter Working, optional Connection,
and Product/Resource Drafts, including their permanent Owner-scoped references.
The resolver is STABLE with an empty search path, grants only authenticated
execution, and accepts no Owner, Item or destination argument. It requires an
active incomplete Owner at the S6 frontier and all preceding prerequisites.
Reads create no Working, Draft, reservation, preview receipt or public state.

Exact source URL and SHA-256 binding, verdict revision and unexpired safe status
determine destination eligibility. Missing, pending, expired, review and blocked
sources are explicitly ineligible. Source changes cannot inherit old URL safety.
Product publication needs a recognizable title and source; Resource needs explicit
meaning, recognizable title and source. Every Item also needs its matching
permanent Resource/Product identity reservation. These checks are preview advice;
the eventual Publish transaction must repeat them under appropriate locks.

Identity Connection safety participates in Identity validity. A saved unsafe
connection is shown as an issue to fix, never silently omitted or made clickable.
Selected Profile Media may be previewed with the existing short-lived private
server-signed URL. Public media preparation is a later contract: the preview
identifies this unmet publication boundary instead of silently dropping media.

The server returns a SHA-256 digest of the exact canonical preview payload for
subsequent stale-preview binding. The digest itself grants no authority and is
not a publication receipt. Future publication must bind current Owner, verify
explicit intent, reject changed snapshots and repeat validation atomically.
Safety timestamps use UTC so session/Prefer timezone changes do not change an
otherwise identical digest. This is applied through a separate additive migration
after the first preview migration was exercised locally; history is preserved.

The UI renders a responsive intended-public composition, clearly marked private,
and separate review issues for each saved optional Item. Preview never follows
external destinations, records public traffic, uses HTML from Owner input, or
creates dead public Spill CTAs. Current Draft text is rendered as escaped text.
Fix links lead to the existing S3/S5 edit surfaces. Product and Resource remain
retained regardless of changed persona guidance.

First publication is not enabled by this checkpoint. Its later contract must
define explicit Identity-only vs Item bundle selection, durable preview receipt,
atomic publication, duplicate-submit protection, public reads and media transport.
It must retain invalid/unselected Drafts and complete onboarding only after the
first authoritative Identity publication. No S5/S6 closure is claimed here.
