## Database authority

This resolver is not a capability authenticator. Future private assembly MUST

clock/deadline RPC execution remains revoked from public/anon/authenticated/

## Bounded server calibration primitive

Use an injected server Supabase client and monotonic counter (performance.now by
default), not application Date.now, to bound the clock sample round trip. Abort
the read at five seconds and deny malformed/error/noninteger/unsafe epoch values,
nonfinite/negative/backward counters, duration >5,000ms or integer overflow.

At receipt, lower epoch bound is the database sample; upper is sample plus ceil
round-trip milliseconds plus one millisecond for SQL flooring. Advance lower by
floor elapsed monotonic time and upper by ceil elapsed. Any subsequent counter
rollback/nonfinite value or overflow makes both callbacks invalid permanently.
Do not cache/reuse calibration across operations or workers.

Future core wiring MUST use the lower bound to timestamp issuance and the upper
bound for deadline decisions; using one bound for both can either create future
records or extend acceptance. Recheck expiry with the database deadline resolver
after committed consumption. Calibration assumes ordinary clock progression; it
is not proof against database clock discontinuities or changes after a response.
Database create/consume and the final deadline resolver remain authoritative and
fail closed on observed future/expired records. No grace period or TTL extension.
