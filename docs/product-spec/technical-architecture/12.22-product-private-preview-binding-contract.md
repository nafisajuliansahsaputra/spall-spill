## Exact saved snapshot

null before explicit preparation save, otherwise the independent preparation
revision, exact selected canonical image key and ordered structured destinations.
Each destination includes current exact URL/hash-bound safety status, revision
and expiry using the existing private-preview safety contract. Preserve original
affiliate query attribution and array order. Provider recognition is context,
not a safety verdict. Incomplete preparation remains valid private saved work.

The resolver accepts no Owner/Item/image/destination selector, creates no rows,
and reads one coherent saved snapshot. Include all added fields in the canonical
UTC digest. A preparation/image/destination/order/revision change, verdict revision
change or expiration changes that digest; old displayed digests cannot confirm
the new snapshot. Existing confirmation locks Owner/progress and all preparation
mutations lock that Owner, preserving concurrent stale rejection. Receipt remains
review evidence, never publication permission. New schema deployment invalidates
an older Product preview digest even if its original text is unchanged.
